# 🩺 SmartHealth AI

SmartHealth AI is an AI-powered healthcare assistant that helps users access health-related information through a conversational interface.

The project combines Artificial Intelligence, information retrieval, and a collection of WHO health resources to provide relevant and accessible healthcare information.

## 🚀 Features

- 🤖 AI-powered healthcare assistant
- 💬 Conversational interaction with users
- 📚 WHO-based health knowledge resources
- 🔎 Health information retrieval
- 🧠 AI + Retrieval-Augmented Generation (RAG)
- 🖥️ Local application support

## 🛠️ Technologies Used

- Python
- Streamlit
- JavaScript
- Node.js
- ChromaDB
- Retrieval-Augmented Generation (RAG)
- WHO health resources

⚙️ Installation
1. Clone the repository
git clone https://github.com/22rohanbisht-ally/SmartHealthAI.git
2. Navigate to the project
cd SmartHealthAI
3. Create a virtual environment
python -m venv venv
4. Activate the virtual environment

For Windows PowerShell:

.\venv\Scripts\Activate.ps1

If PowerShell blocks activation:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Then activate the environment again:

.\venv\Scripts\Activate.ps1
5. Install dependencies
pip install -r requirements.txt
▶️ Run the Application

Start the Streamlit application:

streamlit run app.py

Then open:

http://localhost:8501
